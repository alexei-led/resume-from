# v0.5.4

## Changes

- The Claude Code plugin now installs from this git repository, pinned to the release tag. Before,
  `claude plugin update` downloaded an npm tarball. npm 12 refuses that with `EALLOWREMOTE` unless
  `allow-remote=all` is set. The plugin no longer needs any npm setting.
- The Claude Code command runs `npx --yes resume-from@<version>`, as the Codex skill does. The plugin
  no longer carries a bundled binary. The first use needs access to the npm registry.
- The Codex command is now a skill. Codex did not load plugin prompt files, so `/resume-from` was
  not found. Run `$resume-from <id>` instead.

## Upgrade

Refresh the marketplace, update the plugin, then restart the agent:

```sh
claude plugin marketplace update alexei-led-resume-from
claude plugin update resume-from@alexei-led-resume-from
```

For Codex, update the plugin and start a new session. Use `$resume-from <id>`; `/resume-from` does
not exist in Codex. If you set `allow-remote=all` only for this plugin, you can remove it.
