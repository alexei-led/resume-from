# v0.5.2

## Fixes

- A Claude Code import no longer fails when the target project directory holds your own files
  beside the sessions, such as notes, scripts, or `briefs/` and `state/` folders. Claude Code
  reads only session files there. The adapter now refuses an import only when it finds an
  unknown `.json` file, which could be a session index that the import would have to edit.

## Upgrade

Update the plugin and restart Claude Code, Codex, or Pi. If an import failed with "is not a
session file this adapter recognises", run `/resume-from <source-id>` again.

[Full changes](https://github.com/alexei-led/resume-from/compare/v0.5.1...v0.5.2)
