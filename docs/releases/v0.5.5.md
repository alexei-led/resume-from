# v0.5.5

## Changes

- Pi imports now honor the effective project session directory set by `--session-dir`, `PI_CODING_AGENT_SESSION_DIR`, or `sessionDir` in settings. Both `sessions` and `sessions-work` layouts and flat custom directories are preserved. Imported sessions are written, read back, and opened at that location instead of moving to the default `~/.pi/agent/sessions` directory.

## Upgrade

Update the `resume-from` package in Pi and restart running Pi sessions to load the extension. No configuration change is needed.

[Full changes](https://github.com/alexei-led/resume-from/compare/v0.5.4...v0.5.5)
