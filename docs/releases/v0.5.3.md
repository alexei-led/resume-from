# v0.5.3

## Changes

- Claude Code and Codex now print `Resume in place: /resume <id>` for the session to open: the
  imported session, or the native session of the active profile. Type it in the agent where you
  ran `/resume-from`. The agent opens the session there and moves to its directory. It keeps its
  own launch settings, so a wrapper such as `claude-work` or extra `--settings` stay in effect.
- The Claude Code and Codex commands no longer start a new agterm session, tmux window or agent
  process. The `Resume:` line is still printed for opening the session from another terminal.
- Pi switches in process from any directory. A native Pi session in another directory, and an
  import whose destination is another directory, now open in the running Pi, which moves to the
  session's directory. A declined or failed switch prints `Resume:`.

## Upgrade

Update the plugin or extension and restart Claude Code, Codex, or Pi.
