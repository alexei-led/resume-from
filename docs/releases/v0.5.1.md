# v0.5.1

## Fixes

- Restoring a personal Claude Code session from a work profile now imports into the active work
  profile. The native-resume shortcut applies only when both the agent and profile home match.
  The same routing fix applies to Codex profiles. Bare-shell restores still print the source
  session's native command without importing.
- Claude Code resume commands keep non-default profile homes explicit, including when the current
  process already uses that profile. Opening another terminal no longer depends on inherited
  `CLAUDE_CONFIG_DIR`.
- The Claude Code command wraps agterm launches in a login shell and uses `--wait` so startup
  errors remain visible. Raw `cd … && …` commands are no longer handed to an argv-only launcher.
  Profiles that need a custom wrapper or extra `--settings` use the same launcher rather than
  starting a bare `claude` with different provider settings.

## Upgrade

Update the plugin and restart Claude Code or Codex. If you previously attempted a personal-to-work
restore on v0.5.0, run `/resume-from <source-id>` again from the intended work profile.

[Full changes](https://github.com/alexei-led/resume-from/compare/v0.5.0...v0.5.1)
